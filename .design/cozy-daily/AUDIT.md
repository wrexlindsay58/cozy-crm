# Audit 1 must-fixes (unchanged)

Do not rewrite these. Execute them.

1. Bad and good wear the same clothes.
   Unmarked, no sit, missed look like inventory. Status color must live on the row or tile, not only a pill.

2. Sales today is first, then the page argues with it.
   The $0 (or whatever sold) owns Today. Yesterday is the pair. Counts do not out-shout money.

3. Equal tiles kill rank.
   No six-up vanity KPIs. Activities is not a peer of appointments. Names beat counts.

4. The selected state is a hairline.
   Selected is fill or a 4px left bar, visible at arm's length. Not a 1px ring.

5. Separation is soft.
   Cards must chunk. No gray-on-gray drill tiles. One page frame.

6. Alignment, space, and color are not a system yet.
   Gaps only 4 / 8 / 12 / 16 / 24 / 32. Header 56. One status map. No chart blue, no mint chips, no logo red in chrome.
