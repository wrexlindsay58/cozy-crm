# Pipeline chrome

The lead file is the reference. Later stages keep this chrome and change the work in the left column.

Lead → Assessment → Opportunity → Job → Account.

Same house. Same thread. Same people. Different work.

## What never changes

- Title, status chip, DND, Call / Text / Book / Create as icons.
- Owner, followers, Follow / Transfer / Merge / Drop.
- 60/40 split. Conversation is always on. Customer, Internal, Notes, Tickets, History, Form.
- Media, tags, workflows, DND types.
- History is a timeline. Internal is the shop. Customer is the house.
- Menus and tooltips stay on screen. Chevrons sit in from the edge.
- Tap 44. Words drop to icons with tooltips when they clip.

## What each stage adds

| Stage | Left column work |
|---|---|
| Lead | Contact, source, interests, book, disposition |
| Assessment | Site packets, photos of the house, what we found |
| Opportunity | Options, proposal, take card |
| Job | Crew, schedule, holds, change orders, invoices |
| Account | Service, warranty, membership, new lead from the house |

## Prior stages

On every file after lead, the earlier files sit in expandable blocks under the stage work.

Closed by default. Open one, read it, keep working. A tab in the conversation pane is the wrong place — that pane is talk. This is file data.

Lead on assessment. Lead + assessment on opportunity. Those plus the proposal on the job. The whole chain on the account, so a repeat buyer still has the first job.
